# Refonte visuelle des fiches — v5.10

## Objectif

Rendre les fiches plus désirables et plus faciles à parcourir sans retirer les
informations techniques ajoutées dans la version précédente.

## Changements réalisés

- système de 17 pictogrammes SVG cohérents, légers et intégrés au code ;
- quatre vignettes de synthèse illustrées : style, dosage, service et accord ;
- repère visuel propre à chaque section ;
- verdict transformé en deux cartes de décision ;
- assemblage et élaboration présentés dans deux cartes éditoriales ;
- dégustation divisée en quatre cartes illustrées : œil, nez, bouche et finale ;
- jauges regroupées dans un bloc sombre plus lisible ;
- accords transformés en pastilles ;
- six caractéristiques essentielles visibles immédiatement ;
- caractéristiques secondaires regroupées dans un seul volet repliable ;
- huit réponses pratiques présentées sous forme de cartes compactes ;
- vignettes de style ajoutées sur les cartes bouteille du catalogue et des
  alternatives ;
- effets de survol, ouverture animée des réponses et apparition progressive ;
- désactivation automatique des animations lorsque l’utilisateur préfère une
  interface sans mouvement.

## Responsive

- quatre colonnes sur grand écran ;
- deux colonnes sur tablette ;
- une colonne sous 520 px ;
- tailles tactiles renforcées sur les accordéons ;
- focus clavier visible ;
- images toujours affichées en `object-fit: contain`.

## Contrôles

- 48 fiches générées ;
- 73 pages HTML ;
- 72 URL dans le sitemap ;
- aucun lien interne cassé ;
- 2 400 profils de recommandation testés ;
- audit de profondeur validé ;
- feu vert lancement validé.
